# 國立臺灣歷史博物館 Web 數位導覽系統 — 觀眾體驗旅程地圖 (User Journey Map v3 全面整合版)

## 1. 專案背景與體驗旅程架構 (Overview & Context)

本文件旨在彙整國立臺灣歷史博物館（簡稱台史博）「Web 數位導覽系統」建置案之**觀眾體驗旅程地圖（User Journey Map v3）**。本版本全面整合了五次需求訪談會議紀錄（2026/10/06、2026/10/16、2026/10/22、2026/10/30 第四次與第五次）及五份語音訪談錄音之第一線實務觀察，涵蓋志工培訓員、資深導覽員、展場服務督導、數創中心 IT 代表、票亭與平權服務人員、公共服務與教育組組長及展場營運組研究人員之跨部門經驗。

### 1.1 系統核心定位與專案目標
* **C 端觀眾（Visitor Experience）**：
  * **零門檻體驗**：免下載專用 App、免排隊租借實體機器，手機掃描 QR Code 即可免費開啟 Web 導覽。
  * **全方位隨身小幫手**：不僅提供語音導覽，更整合空間視覺地圖、設施定位、時間別與主題式路線推薦、設施時刻表排程助手，解決觀眾「進門後不知去哪裡」的迷惘。
* **B 端館員（Admin & Operations）**：
  * **後台模組化與彈性維護**：支援圖文、音訊與手語影片「一鍵上傳」與即時下架/更新，解決過往展品抽換與紙質文物定期輪換時需聯繫外部廠商修改的耗時流程。
  * **減輕第一線與志工負擔**：將重複性基礎諮詢（如廁所、出口、時刻表、交通）自動化，並為志工培訓提供標準數位教材。
* **AI 陪伴導覽員（AI Assistant Integration）**：
  * **聚焦導覽與生活化 FAQ**：定位為「展覽探索與實用 FAQ 助手」，提供一問一答引導式卡片與自然語言對話，解答展覽深度細節及實用生活提問（廁所、叫車、時刻表、周邊美食），不將無解問題轉拋給現場館員。
* **數據分析與管考呈報**：
  * 串接 Google Analytics (GA4) 與館方智慧服務平台數據 API，即時統計月/年使用人次、展點點擊率、停留時間與收藏足跡，滿足立委質詢與科技計畫管考報表匯出需求。

## 2. 多重觀眾輪廓與心智模式 (Visitor Personas)

```
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│                                   台史博多元觀眾輪廓 (Personas)                             │
├───────────────────┬───────────────────┬───────────────────┬───────────────────────────────┤
│  一般散客 / 大眾  │   親子家庭 / 兒童 │ 歷史學者 / VIP貴賓 │ 樂齡 / 平權 / 外國遊客        │
├───────────────────┼───────────────────┼───────────────────┼───────────────────────────────┤
│• 偏好生活化八卦   │• 被亮光螢幕/模型/ │• 關注空間設計理念 │• 樂齡：子母機需調音量指引     │
│  與趣味主題路線   │  動畫/水牛人像吸引│  與重磅典藏/史料  │• 聽障：需要自主手語導覽影片   │
│• 怕嚴肅與冗長歷史 │• 低年級易疲累     │• 探索展區脈絡巧思 │• 視障：七大實體觸摸展區       │
│• 需要時間別指引   │• 孩子多無個人手機 │• 挑戰專業知識邊緣 │• 外籍：韓語/英語高頻詢問交通  │
└───────────────────┴───────────────────┴───────────────────┴───────────────────────────────┘
```

1. **一般觀眾與散客**：重視生活化、故事性與趣味主題（如「臺灣違法亂紀與詐騙史」），希望無負擔觀展，需要 30 分鐘/1 小時等時間別路線推薦。
2. **親子家庭與兒童**：容易被亮光螢幕、立體模型（Diorama）、動畫、水牛與下水玩水人像吸引。小學低年級觀眾通常逛到戰後展區即顯疲累；多數孩子無個人手機，兒童版與成人版選件及號碼標示需妥善對接。
3. **歷史學者與 VIP 貴賓**：關注展覽空間設計理念（如 4F 俯瞰點）、人群像宣示、重磅典藏與特殊展示巧思，重視多源史料脈絡。
4. **樂齡與無障礙/平權觀眾**：
   * **樂齡團體**：即便使用結構簡單的團體子母機，仍常詢問如何調整音量。
   * **聽障觀眾**：過去多依賴團體預約手語翻譯，Web 導覽提供自主手語影片可大幅提升獨立參觀彈性；服務台另備有筆談服務。
   * **視障觀眾**：多由家人陪同，需指引至七大實體觸摸展區（如舊時平息爭端的公頭秤）。
   * **輪椅社福團體**：主要需求為電梯協助、無障礙廁所與通廊引導。
5. **外國遊客**：英語與日語需求穩定，韓語需求迅速提升（過往常因欠缺韓語導覽機而放棄租借）；高頻詢問館內 Wi-Fi 與離館交通（計程車叫車點）。

## 3. 全流程五大階段 觀眾體驗旅程詳細拆解 (End-to-End User Journey)

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ 階段一：抵達購票 │──>│ 階段二：大廳分流 │──>│ 階段三：取得導覽 │──>│ 階段四：展場參觀 │──>│ 階段五：售後反饋 │
│ (戶外與售票亭)   │   │ (8號門與大廳)   │   │ (掃碼與適應)    │   │ (核心展區互動)  │   │ (離館與雙向溝通)│
└─────────────────┘   └─────────────────┘   └─────────────────┘   └─────────────────┘   └─────────────────┘
```

### 階段一：抵達與購票（參觀前至戶外/售票亭）

* **觀眾行為 (Actions)**
  * 搭乘公車、計程車或自駕抵達（區分公務停車場與遊客停車場）。
  * 步行經過長草皮步道走向展館入口。
  * 於戶外售票亭排隊購票，並使用周邊公共設施（自動售票機、販賣機、戶外廁所）。
  * 向售票人員或第一線團隊詢問周邊交通（公車、計程車叫車）、餐飲選擇（館內僅一間咖啡廳）及周邊景點（如亞太棒球場）。
* **接觸點 (Touchpoints)**
  * 停車場、長草皮步道、售票亭、自動售票機、戶外告示牌、戶外廁所、自動販賣機。
* **現場痛點 (Pain Points)**
  1. **定位與停車場混淆**：Google Map 早期定位至行政大樓/公務停車場，民眾常被警衛攔下後需繞回遊客停車場。
  2. **團體票強制綁定導覽設備**：現行團體票價（約每人 90 元）綁定團體子母機費用，部分無導覽需求團體質疑無法退費降價。
  3. **外籍語言缺口**：韓語遊客因現場缺乏韓文導覽機而放棄租借。
  4. **設施不便**：館內餐飲選擇少、無 ATM，民眾習慣直接於售票口詢問服務人員。
* **Web 導覽 UI/UX 與營運優化策略 (Solutions)**
  * **入口 QR Code 前置**：於售票亭及入口顯眼處張貼 Web 導覽 QR Code，標註「免下載 App、免排隊租機、免費開啟」。
  * **多語系支援**：預設華語、英語、日語、韓語四種語言介面與語音，並預留東南亞語系擴充架構。
  * **售前資訊預覽**：開啟 Web 即可預覽特展、常設展亮點、參觀時間預估與周邊餐飲/交通指引。

### 階段二：大廳入場與分流決策（參觀初期）

* **觀眾行為 (Actions)**
  * 刷票入館進入寬覽大廳，面臨多向分流抉擇：
    * 向左走樓梯或向右搭手扶梯直上 **2F 常設展**；
    * 前往 **1F 兒童廳**；
    * 或走向右側遠端的 **1F 服務台** 進行預約或諮詢。
  * 查看大廳全館平面圖，家長思考兒童廳與常設展順序。
  * 詢問特殊設施時刻表（時光車站火車劇場、圓形劇場、VR 體驗區、兒童廳）。
* **接觸點 (Touchpoints)**
  * 8號門入口、刷票閘門、大廳空間、手扶梯/樓梯、全館 2D/3D 平面導覽圖、1F 服務台。
* **現場痛點 (Pain Points)**
  1. **入口不直覺與視野盲點**：館方將正門由 1 號門改為 8 號門（原小門），前庭短且緊接手扶梯；1F 服務台原本配合 1 號門設置，現位於右側遠端，民眾無法第一眼看到。
  2. **空間茫然感與無 3 樓誤解**：二樓挑高直達四樓，民眾常誤以為有 3 樓；搭電梯至 4F 後找不到特展室（如媽祖特展位於四樓電梯左手邊第一特展室，缺乏顯眼指標）。
  3. **設施時刻表與排程焦慮**：時光車站（半小時一場/預約制）、圓形劇場（半年換片）、VR 體驗（上下午分段報名）與兒童廳（平假日模式）各有不同規則，觀眾常感到排程焦慮。
* **Web 導覽 UI/UX 與營運優化策略 (Solutions)**
  * **大廳首頁即時分流地圖**：提供全館視覺平面圖，標示目前位置、1F/2F/4F 核心展區與服務台位置，並強化 4F 特展視覺引導。
  * **時間別與主題別包囊推薦**：提供「30 分鐘快速看」、「1 小時精華巡禮」、「2 小時深度探索」及「生活故事主題（如：臺灣違法亂紀史）」路線。
  * **設施時刻表與排程小助手**：系統整合各設施場次與報名限制，自動建議最佳參觀順序（如先搶限額 VR 預約 ➔ 時光火車 ➔ 常設展導覽）。

### 階段三：取得導覽與環境適應（參觀準備）

* **觀眾行為 (Actions)**
  * 觀眾開啟 Web 導覽系統，挑選偏好的語音版本或手語專區。
  * 戴上自備的手機耳機（若未帶耳機，可至 1F 賣店購買平價一次性耳機或轉接頭）。
  * 進入 2F 常設展或 4F 俯瞰點開始參觀。
* **接觸點 (Touchpoints)**
  * 個人手機、自備耳機、1F 賣店/售票處、展場入口 A5 告示卡。
* **現場痛點 (Pain Points)**
  1. **聲音外放干擾**：館內禁止小蜜蜂擴音，若觀眾未帶耳機將手機聲音外放，會干擾展場安寧及其他觀眾。
  2. **號碼貼紙尺寸過小與摳壞**：傳統號碼貼紙尺寸小、採半透明白底貼於展板，易對比不足；貼紙位於展櫃內外無統一邏輯；常被兒童手摳損壞；展示組維護美觀（「貼大 QR Code 是對台灣科技的侮辱」）與觀眾尋找效率產生拉鋸。
  3. **Wi-Fi 自動斷線與無法漫遊**：館內 iTaiwan 頻寬上限 5 Mbps、30 分鐘強制登出且跨展區無法漫遊；5-6 年前 iBeacon 停用（定位不穩、貼紙脫落、電池維護難）。
  4. **親子共用耳機限制**：家長無多餘手機給孩子，共用耳機受距離限制，且兒童版與成人版選件及號碼標示不一致。
* **Web 導覽 UI/UX 與營運優化策略 (Solutions)**
  * **耳機提醒與友善提示**：播放語音前跳出溫馨提示「請配戴耳機收聽，共同維護觀展品質」，無耳機者指引至 1F 賣店購買。
  * **標準化 A5 視覺告示卡**：淘汰易摳壞的小貼紙，採用高辨識度標準化 A5 告示卡，會同公服組與展示組實地會勘放置於公共通道牆面。
  * **PWA 輕量化與離線快取**：採用 PWA 輕量化快取技術，適應 iTaiwan 斷線風險，並配合數創中心於重點展區開立專用頻寬（獨立 SSID）。

### 階段四：展場內參觀與深度互動（核心體驗）

* **觀眾行為 (Actions)**
  * 依選定路線進行參觀：
    * **學者/貴賓路線**：4F 俯瞰點 ➔ 2F 人群像宣示 ➔ 原住民/小人物視角 ➔ 藝陣區 ➔ 日治派出所與街屋 ➔ 228/戰後 ➔ 大眾博物館投票。
    * **故事/生活路線**：聆聽生活化歷史故事與八卦脈絡（如 17-18世紀福爾摩沙偽書騙局、土地掠奪與走私、媒體假消息）。
    * **親子/兒童路線**：尋找亮光模型（Diorama）、水牛、下水玩水人像，體驗快閃叫賣/戲劇，或搭配「萬石歷險團」實境解謎包與學習單。
  * 遇到疑問時，使用系統內的 **AI 陪伴導覽員** 進行互動問答。
* **接觸點 (Touchpoints)**
  * 4F 俯瞰點、2F 常設展各大展區、展場牆面/通道 A5 告示卡、AI 陪伴導覽員介面。
* **現場痛點 (Pain Points)**
  1. **展品抽換與說明牌時間差**：紙質文物定期輪換或修館撤下時，若無告示，導致現場展品與既有導覽或說明牌不符，觀眾質疑服務人員。
  2. **開放式展間動線跳躍**：展區為開放式無固定順序，號碼跳躍（如找完 4 號找到 6 號，找不到 5 號）導致觀眾歸還機器時抱怨動線不順。
  3. **現場提問人力有限**：志工到館頻率低（一週半天），主要負責巡場；第一線服務人員 17 位繁忙，觀眾遇到深層問題不敢或無法即時獲得解答。
  4. **解謎包/學習單卡關**：亞運學習單或萬石歷險解謎包手機當機/找不到答案時跑至服務台求助。
* **Web 導覽 UI/UX 與營運優化策略 (Solutions)**
  * **展區脈絡化導覽**：腳本以「展區概念與歷史脈絡」為主，避開易更換單一展品，維持內容長期有效性；後台支援「一鍵標註維護中」。
  * **線上地圖點位索引**：提供 2D 展區點位導引，減輕觀眾對號碼順序的迷惘。
  * **AI 陪伴式導覽員 (生活化 FAQ + 展覽探索)**：
    * **角色定位**：聚焦展覽本身與延伸歷史問答，以及實用生活 FAQ（廁所、設施時刻表、離館叫車、周邊美食）。
    * **對話形式**：一問一答引導式卡片（如「為什麼這裡有派出所？」、「你最喜歡什麼體育運動？」），不將無解問題轉拋給館員。
  * **無障礙專區**：提供華/英/日/韓切換、手語導覽影片專區（取代 YouTube 分散連結）及七大觸摸展區地圖（配合筆談與無障礙電梯）。

### 階段五：參觀後離館與雙向反饋（售後與深化）

* **觀眾行為 (Actions)**
  * 閉館前（16:30 停止售票、16:40 8號門預備關閉、17:00 準時閉館）順著動線離館。
  * 離開時尋找出口、詢問離館交通（計程車叫車、公車）及周邊美食。
  * 回家後複習參觀歷程、購買特展/常設展圖錄，或透過線上管道反饋意見。
* **接觸點 (Touchpoints)**
  * 6號門出口、洽公停車場（計程車搭乘點）、個人參觀歷程頁面、線上館長信箱、實體觀眾意見箱、台史博官方 Facebook 粉絲專頁。
* **現場痛點 (Pain Points)**
  1. **出口走錯與繞行**：採「8號門進、6號門出」單向流線，觀眾常習慣原門（8號門）離開而被擋下，抱怨還機器與離館動線順暢度。
  2. **離館交通與叫車困擾**：外地/外籍觀眾離館時不知何處搭計程車，服務台需人工撥打多家車行電話並指引至「洽公停車場」搭車。
  3. **反饋管道分散與處理時間差**：意見分散於實體意見箱、館長信箱與 FB 私訊；第一線閉館會議記錄累積 10 幾年未系統化整理。
* **Web 導覽 UI/UX 與營運優化策略 (Solutions)**
  * **免去還機繞行痛點**：手機導覽直接隨身帶走，無須繞回 8 號門票亭還機。
  * **離館交通與出口指引**：地圖明確標示 6 號門出口方向、洽公停車場計程車搭乘點及周邊公車與餐飲資訊。
  * **參觀歷程與收藏足跡**：提供「我的參觀足跡」與展品收藏功能，方便回家複習與開啟延伸數位典藏。

## 5. 跨部門營運配合與會後追蹤事項 (Cross-Department Action Plan)

1. **實體標籤與 A5 告示卡會勘**：
   * 需會同**公服組**、**展示組**與**秘書室**進行現場會勘，選定公共通道牆面設置標準化 A5 告示卡，原則為「避開歷史情境（如藝陣區）、統一視覺風格、考量兒童與輪椅視線高度」。
2. **館內網路與專用頻寬開立**：
   * 與**數位創新中心（數創中心）**對接，於展場重點區域開立獨立 Dedicated Wi-Fi 頻道（獨立 SSID），避開 iTaiwan 5Mbps 頻寬限制與 30 分鐘重連機制。
3. **賣店耳機與轉接頭銷售**：
   * 請公服組協調 1F 賣店與售票處備妥平價 3.5mm / Type-C / Lightning 一次性耳機與轉接頭，配合導覽系統之耳機提示進行販售。
4. **資料串接與後台維護**：
   * 展覽資料對接文化部藝文活動平台 API 與官網 API；後台提供「一鍵發布/下架」與展品維護標註，簡化同仁上稿流程。
5. **數據儀表板與管考呈報**：
   * 後台串接 GA4 與智慧服務平台 API，即時統計使用人數 (UV)、展點點擊率、停留時間與收藏足跡，支援一鍵匯出 CSV/XLSX 報表，因應立委質詢與科技計畫呈報。
