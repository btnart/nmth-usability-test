- 狀態是設計端的**初步標註**，待專案經理與館方確認：
  - **確定**＝第 1 輪易用性測試已測、已依結果修正，且屬核心流程或 11/13 協調會報已有決議

  - **未設計**＝規格或決議有提到，原型沒有

## 資訊架構（階層）

```
落地頁
└─ 首頁
   ├─ 今日活動 → 活動詳情 → 今日行程
   ├─ 展覽
   │   └─ 展覽頁 → 導覽清單（單元 → 子單元 → 展品）→ 展品頁 → 播放器
   │                 └─ 展覽地圖
   ├─ 展區地圖 → 找設施／找展覽／找出入口／帶我去
   ├─ 主題路線
   ├─ 常見問題
   ├─ 意見回饋
   ├─ 無障礙服務
   ├─ 離館指南
   └─ 網站導覽
掃碼／輸入編號（浮動按鈕，多數頁面可用）→ 展品頁 → 播放器
選單 → 會員（登入／我的收藏／導覽歷程／我的筆記）、離館與交通、設定（語言、字級與高對比、離線預載、帳號與隱私）
```

## 深連結（供 QR Code 規格參考）

原型支援以網址參數直接進入畫面，QR Code 規格可沿用此思路：

- `#nmth&go=home`：首頁
- `#nmth&go=ex:<展覽代碼>`：展覽頁（展場入口 QR Code）
- `#nmth&go=pt:<3 位編號>`：掃到展籤，帶入編號（只有具語音導覽的內容有編號，見上表）
- `#nmth&go=map:<樓層>`：地圖指定樓層
- `#go=sign`：手語導覽專用 QR Code
