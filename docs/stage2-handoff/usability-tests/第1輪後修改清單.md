## 語言規則（11/12 內部會議初步結論，待館方確認）

原型已全站套用。

- **介面語言決定語音**：中文介面＝華語（台語、客語音軌也屬中文介面）；英、日、韓介面只顯示同語言的語音
- **手語影片**＝臺灣手語附中文字幕，只在中文介面出現
- **沒有同語言語音、也沒有手語**＝只有展品介紹文字：沒有播放器；展覽頁按鈕改成「閱讀導覽」（書本圖示），一樣可以依序看展品介紹；卡片與展覽頁不加任何語言標籤，數量寫「N 件展品」
- **AI 翻譯**：外文的展品介紹標示「AI 翻譯」
- **手語專用 QR Code**（標書「建置常設展手語導覽」：手語導覽模組＋QR Code 1 式）：掃描直接進手語導覽總覽；中文介面直接進；英日韓先跳彈窗問是否切換中文，同一次瀏覽只問一次。從選單進入且是外文介面時，顯示「手語影片在中文介面提供」＋切換按鈕
- **目前語言範圍**：常設展只有手語；萬相天后、邊界之外只有中、英語音；參觀前先聽＝中英日韓＋手語。所以日、韓介面下，常設展與兩檔特展都只有文字
