## T1 換語言（從落地頁開始）

**操作步驟**
1. 落地頁正中間只有「開始導覽」和下面的「繁體中文・Language」，直接點語言按鈕 → 跳出語言選單（`T1-01-落地頁.png`、`T1-02-語言選單.png`）
2. 點「English」→ 選單關掉，按鈕變成「English・Language」，但標題「臺史博語音導覽」、「開始導覽」、「內容已準備好」都還是中文，看不出來有沒有換好（`T1-03-選English後.png`）
3. 為了確認，點「開始導覽」→ 首頁大部分變英文，確認換好了（`T1-04-開始導覽後.png`）
4. 點右上「English / Language」膠囊按鈕 → 跳出同一個語言選單（`T1-05-首頁語言選單.png`）
5. 點「繁體中文」→ 換回中文（`T1-06-換回中文.png`）

**答案**：一開始的畫面在「開始導覽」下面的「繁體中文・Language」；進去後在右上角的「語言 / Language」。
**對錯**：對（落地頁＋首頁右上兩個入口都找到；沒用到 ☰）。
**完成狀態**：我完成了｜**秒數**：約 40｜**SEQ**：5
**卡關**：不知道在哪個畫面（選完 English 後落地頁沒變，要再點進去才確認）
**感受**：「按鈕很好找，可是選完英文畫面還是中文，我還以為沒按到。」
